Host page (simulated customer site)

The floating chat button bottom-right is the Raggie external widget, loaded by a single <script> tag and fully isolated in a Shadow DOM. Replace WORKSPACE_ID below (and the origin, if your front door is not http://localhost).

This page's CSS cannot leak into the widget and vice-versa. The widget only talks to the widget paths of the front door; the admin surface is unreachable from here.
